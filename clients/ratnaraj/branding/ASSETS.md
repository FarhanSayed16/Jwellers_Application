# Branding assets — drop files here

## Required

| File | Suggested name | Notes |
|---|---|---|
| Logo (transparent PNG) | `logo.png` | High resolution |
| Logo dark-bg variant (optional) | `logo-on-dark.png` | If gold logo needs dark version |
| App icon source | `app-icon.png` | 1024×1024 preferred |

## Optional

| File | Suggested name |
|---|---|
| SVG logo | `logo.svg` |
| Hero banner | `hero.jpg` |
| Watermark mark | `watermark.png` |

Update `tokens.json` when Client confirms final colors.  
If files are too large for git, put Drive/Dropbox links in `../links.md` and keep only small logos here.
